m5数据处理

在数据科学和机器学习领域，M5数据处理通常指的是针对 Kaggle 经典时间序列预测赛事 M5 Forecasting Competition（沃尔玛销量预测）的数据集清洗与特征工程。
该数据集由于包含多层级聚合、大量缺失值（如未上架商品）以及多表关联，数据处理的效率和质量直接决定了后续 LightGBM 等模型的预测准确度。

📂 一、 M5 数据集核心构成

在开始处理前，需要读入并理解官方提供的三个核心文件：
1. sales_train_evaluation.csv：销售历史数据。包含 30490 个商品在 10 个店铺（分属 CA、TX、WI 三个州）共 1941 天的日销量。
2. sell_prices.csv：价格数据。包含各商店商品每周的销售价格。
3. calendar.csv：日历数据。包含日期对应的节日活动（如超级碗、情人节）、是否发薪日（SNAP）等特征。

🛠️ 二、 M5 数据处理核心步骤与代码


1. 数据降维与长表转换（Melting）

原始销售数据是“宽表”格式（一天一列，从 d_1 到 d_1941），不利于机器学习模型训练。我们需要使用 pd.melt 将其转换为“长表”格式，并转换数据类型以节省内存。
python
import pandas as pd
import numpy as np

def reduce_mem_usage(df):
    """通过优化数值类型显著降低内存占用"""
    for col in df.columns:
        col_type = df[col].dtype
        if col_type != object:
            c_min = df[col].min()
            c_max = df[col].max()
            if str(col_type)[:3] == 'int':
                if c_min > np.iinfo(np.int8).min and c_max < np.iinfo(np.int8).max:
                    df[col] = df[col].astype(np.int8)
                elif c_min > np.iinfo(np.int16).min and c_max < np.iinfo(np.int16).max:
                    df[col] = df[col].astype(np.int16)
                elif c_min > np.iinfo(np.int32).min and c_max < np.iinfo(np.int32).max:
                    df[col] = df[col].astype(np.int32)
            else:
                if c_min > np.finfo(np.float16).min and c_max < np.finfo(np.float16).max:
                    df[col] = df[col].astype(np.float16)
                elif c_min > np.finfo(np.float32).min and c_max < np.finfo(np.float32).max:
                    df[col] = df[col].astype(np.float32)
    return df

# 1. 读取并 Melt 销售数据
sales = pd.read_csv('sales_train_evaluation.csv')
sales_melt = pd.melt(sales, 
                     id_vars=['id', 'item_id', 'dept_id', 'cat_id', 'store_id', 'state_id'], 
                     var_name='d', 
                     value_name='sales')
sales_melt = reduce_mem_usage(sales_melt)

2. 清除未上架前的“无效零值”

许多商品在 1941 天的早期阶段根本没有上架，此时的销量为 0 属于无效噪声。可以通过多表联查，找出每个商品在各商店第一次出现价格的周，并将该周之前的数据全部切除。
python
prices = pd.read_csv('sell_prices.csv')
calendar = pd.read_csv('calendar.csv')

# 找出每个商品在每个商店的首次上架周（wm_yr_wk）
release_df = prices.groupby(['store_id', 'item_id'])['wm_yr_wk'].agg(['min']).reset_index()
release_df.columns = ['store_id', 'item_id', 'release_week']

# 将日历的 'd' 与周次合并
calendar_release = calendar[['d', 'wm_yr_wk']].drop_duplicates()

# 过滤销售数据，只保留上架后的数据
sales_melt = sales_melt.merge(calendar_release, on='d', how='left')
sales_melt = sales_melt.merge(release_df, on=['store_id', 'item_id'], how='left')
sales_melt = sales_melt[sales_melt['wm_yr_wk'] >= sales_melt['release_week']].reset_index(drop=True)

3. 特征工程构建（Feature Engineering）

这是 M5 预测中最重要的部分，通常构造以下三类特征：
• 历史滞后特征（Lag Features）：因为要预测未来 28 天，所以一般从 lag_28 开始构建，避免数据泄露。
• 滚动窗口统计（Rolling Window）：计算不同窗口大小的均值、标准差等。
• 价格与日历特征：价格变动趋势、是否周末、是否节日、节日前后影响等。
python
# 注意：为了避免内存溢出，建议对 dataframe 进行排序后按组使用 shift
sales_melt.sort_values(by=['id', 'd'], inplace=True)

# 1. 滞后特征 (以28天和30天为例)
sales_melt['lag_28'] = sales_melt.groupby('id')['sales'].shift(28)
sales_melt['lag_30'] = sales_melt.groupby('id')['sales'].shift(30)

# 2. 滚动统计特征 (基于 lag_28 计算，防止预测期数据泄露)
sales_melt['rolling_mean_7'] = sales_melt.groupby('id')['lag_28'].transform(lambda x: x.rolling(7).mean())
sales_melt['rolling_std_7']  = sales_melt.groupby('id')['lag_28'].transform(lambda x: x.rolling(7).std())
sales_melt['rolling_mean_28'] = sales_melt.groupby('id')['lag_28'].transform(lambda x: x.rolling(28).mean())

# 3. 价格特征衍生
prices['price_max'] = prices.groupby(['store_id', 'item_id'])['sell_price'].transform('max')
prices['price_min'] = prices.groupby(['store_id', 'item_id'])['sell_price'].transform('min')
# 当前价格相对于历史最高价的比例（反映折扣力度）
prices['price_momentum'] = prices['sell_price'] / prices['price_max'] 

# 4. 最终大表合并
final_df = sales_melt.merge(calendar, on='d', how='left')
final_df = final_df.merge(prices, on=['store_id', 'item_id', 'wm_yr_wk'], how='left')
